# [cite_start]Todo アプリケーション [cite: 1]

[cite_start]FastAPIフレームワークを用いて作成したTodo管理アプリケーションです [cite: 6, 70]。
[cite_start]提示された要件定義書の機能要件・ユースケースを網羅しつつ、ユーザーの操作性を意識したUX設計を行っています [cite: 6, 9]。

---

## [cite_start]?? 要件定義に基づく「実装済み機能」一覧 [cite: 6]

[cite_start]提示された仕様書の項目に基づき、以下の機能をすべて実装完了しています [cite: 6]。

### [cite_start]1. タスク管理機能 (CRUD) [cite: 17]
* [cite_start]**タスクの追加 (ユースケース1 準拠)** [cite: 26, 78]
  * [cite_start]ユーザーはタイトルと任意の詳細を入力して新しいタスクを作成できます [cite: 27][cite_start]。各タスクには自動的に作成日時が付与されます [cite: 28]。
  * [cite_start]初期画面のノイズを減らすためフォームは隠しておき、右上の「＋ タスクを追加」ボタンを押した時のみトグルで出現します [cite: 84, 85]。開いている間はボタンが「? 戻る」に切り替わります。
* [cite_start]**タスクリストの表示とフィルタリング** [cite: 29, 31]
  * [cite_start]全タスクを一覧形式で表示します [cite: 30][cite_start]。既定のホーム画面となっています [cite: 81]。
  * [cite_start]画面上部のボタンにより、「すべて」「未完了」「完了済み」のフィルタリングが行えます [cite: 31]。
* [cite_start]**タスクの編集 (ユースケース2 準拠)** [cite: 32, 89]
  * [cite_start]タスクの行（文字エリア）をクリックすると、対象のタスクが**青枠の選択状態**になり、最上部のフォームにデータが同期されて編集モードに入ります [cite: 93, 94]。
  * アプリ全体のデザインの一貫性を保つため、「変更を保存」ボタンの色は新規追加時と同じ「緑（白抜き）」に統一しています。
* [cite_start]**タスクの状態管理 (ユースケース3 準拠)** [cite: 37, 97]
  * [cite_start]タスク左側のチェックボックスにより、完了と未完了を切り替えられます [cite: 39, 101][cite_start]。完了済みタスクには取り消し線が入ります [cite: 45, 102]。
* [cite_start]**タスクの削除 (ユースケース4 準拠)** [cite: 35, 103]
  * [cite_start]タスクが選択され、編集モードになっている時のみタスクの削除が可能です [cite: 105]。
  * フォーム内の「変更を保存」ボタンの下にある「このタスクを削除する」ボタンを押すことで削除を行うことができます。
  * [cite_start]誤操作を防ぐため、削除前に確認のプロンプト（ポップアップ）を表示します [cite: 36, 108]。

### [cite_start]2. ユーザーフィードバック・エラー処理 [cite: 51, 54]
* **画面のノイズ削減**
  * フォーム（追加・編集）が開いている間は、下部のフィルターボタンが自動的に非表示になり、ユーザーが目の前の入力・操作に集中できるクリーンな状態を作ります。
* [cite_start]**エラー処理** [cite: 54]
  * [cite_start]タイトルが空の状態で送信されるのを防ぐ適切な入力バリデーション（エラー処理）を施しています [cite: 55]。

## [cite_start]? セットアップ・起動手順 [cite: 6]

### 1. 仮想環境の作成と有効化
プロジェクトのルートディレクトリで以下のコマンドを実行し、Pythonの仮想環境を構築してアクティベートします。

python -m venv .venv　　　　　　 仮想環境の構築
.venv\Scripts\Activate.ps1      仮想環境のアクティベート

### 2. パッケージの一括インストール [cite: 6]
リポジトリに含まれる `requirements.txt` を使用して、必要なパッケージを一括でインストールします。

pip install -r requirements.txt

### 3. サーバーの起動
以下のコマンドを実行し、Uvicornサーバーを起動します。

uvicorn main:app --reload

起動後、ブラウザで `http://127.0.0.1:8000` にアクセスすることでアプリケーションを使用できます。
