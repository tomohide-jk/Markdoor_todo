# Todo アプリケーション

FastAPIフレームワークを用いて作成したTodo管理アプリケーションです。
提示された要件定義書の機能要件・ユースケースを網羅しつつ、ユーザーの操作性を意識したUX設計を行っています。

---

## 要件定義に基づく「実装済み機能」一覧

提示された仕様書の項目に基づき、以下の機能を実装しています。

### 1. タスク管理機能 (CRUD)
* **タスクの追加 (ユースケース1 準拠)**
  * ユーザーはタイトルと任意の詳細を入力して新しいタスクを作成できます。各タスクには自動的に作成日時が付与されます。
  * 初期画面のノイズを減らすためフォームは隠しておき、右上の「＋ タスクを追加」ボタンを押した時のみトグルで出現します。開いている間はボタンが「? 戻る」に切り替わります。
* **タスクリストの表示とフィルタリング**
  * 全タスクを一覧形式で表示します。既定のホーム画面となっています。
  * 画面上部のボタンにより、「すべて」「未完了」「完了済み」のフィルタリングが行えます。
* **タスクの編集 (ユースケース2 準拠)**
  * タスクの行（文字エリア）をクリックすると、対象のタスクが**青枠の選択状態**になり、最上部のフォームにデータが同期されて編集モードに入ります。
  * 編集モードに入ると、選択したタスクの**「タイトル」と「詳細説明」のデータが最上部のフォーム内に自動的に返ってきて入力された状態になり、内容を自由に書き換えることができます。
  * フォーム内のボタンが「変更を保存」に切り替わり、これを押すことでバックエンドにデータが送信され、タスク情報が正しく更新されます。
* **タスクの状態管理 (ユースケース3 準拠)**
  * タスク左側のチェックボックスにより、完了と未完了を切り替えられます。完了済みタスクには取り消し線が入り、文字色が薄くなります。
* **タスクの削除 (ユースケース4 準拠)**
  * タスクが選択され、編集モードになっている時のみタスクの削除が可能です。
  * フォーム内の「変更を保存」ボタンの下にある「タスクを削除」ボタンを押すことで削除を行うことができます。
  * 誤操作を防ぐため、削除前に確認のプロンプトを表示します。

### 2. ユーザーフィードバック・エラー処理
* **画面のノイズ削減**
  * フォーム（追加・編集）が開いている間は、下部のフィルターボタンが自動的に非表示になり、ユーザーが目の前の入力・操作に集中できるクリーンな状態を作ります。
* **エラー処理**
  * タイトルが空の状態で送信されるのを防ぐ適切な入力バリデーション（エラー処理）を施しています。

## セットアップ・起動手順

### 1. 仮想環境の作成と有効化
プロジェクトのルートディレクトリで以下のコマンドを実行し、Pythonの仮想環境を構築してアクティベートします。

1. `python -m venv .venv`　　　　　　 仮想環境の構築

2. `.venv\Scripts\Activate.ps1`      仮想環境のアクティベート

### 2. パッケージの一括インストール
以下のコマンドを実行し、必要なパッケージを一括でインストールします。

`pip install -r requirements.txt`

### 3. サーバーの起動
以下のコマンドを実行し、Uvicornサーバーを起動します。

`uvicorn main:app --reload`

起動後、ブラウザで `http://127.0.0.1:8000` にアクセスすることでアプリケーションを使用できます。
